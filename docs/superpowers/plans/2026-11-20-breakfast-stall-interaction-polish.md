# 《摊位凑一单》开工单与交互动效实施计划

以已确认的手机比例试玩草图为准。问号放在招牌左侧，齿轮放在右侧。帮助弹窗居中，复用现有食物图集、米白纸张、搪瓷绿和笑脸包子。设置弹窗靠近齿轮，两个开关支持整行触摸。

1. 在 `runtime/help-demo.ts` 用正式规则构造一个独立试玩。A 单要茶叶蛋，B 单要米糕。先点蛋应提示遮挡，点米糕后入碟并露蛋，点蛋后依次封 A 单、把暂存米糕补给 B 单。刷新试玩可重来。两次取食物和一次重玩均通过 `cocos-game/tests/settings-hit.test.cjs` 覆盖。
2. 在 `OrderHud.ts` 增加帮助和设置弹窗。遮罩独占触摸，空白吃掉触摸，点外侧或关闭键退出。弹窗按安全区缩放。试玩动画期间仍可关闭弹窗。关闭、切后台或改变窗口大小后清理当前动画。
3. 在 `BreakfastGame.ts` 管理当前弹窗与试玩输入。试玩只读既有声音和动效设置，所有取食物操作只应用到独立试玩状态，退出可继续原关。两个设置开关使用已有进度存储。试玩默认可点物料和底部引导按钮，完成后提供重玩。
4. 在 `StallBoard.ts` 调整真实关卡的入碟落位、遮挡提示和封袋落印。自动换单沿用规则事件顺序。精简动效直接呈现结果并保留提示。
5. 跑 TypeScript 检查、Node 单测和微信发布包构建。在微信 IDE 用同一份包截图核对帮助三步、重玩设置、遮罩关闭以及弹窗前后实际关卡。把复测入口加到现有开发排障手册。
